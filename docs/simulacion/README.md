# Simulación completa del flujo

`simulacion-flujo.mp4` (~1 min) es una grabación automatizada con Playwright de la app real corriendo con datos simulados. Muestra: login → check-in emocional → Reci (pedido por lenguaje natural autocompletado con el perfil) → confirmación con confeti → consulta de impacto → "ver mis solicitudes" (navegación por comando) → salas → chat en vivo → perfil y cambio de tamaño de letra.

| # | Captura | Qué demuestra |
|---|---|---|
| 00 | login | Estilo visceral heredado: papel, starbursts, verde |
| 01 | inicio-ciudadano | Saludo con tono emocional, CTA de voz, check-in, "lo de siempre" (personalización), nivel e impacto |
| 02 | reci-bienvenida | Saludo personalizado según el material habitual |
| 03 | reci-borrador | Pedido en lenguaje natural; franja y dirección autocompletadas "✨ de tu perfil" |
| 04 | reci-impacto | Respuesta reflexiva: kg, CO₂ y árboles |
| 05 | modal-lo-de-siempre | Asistente táctil prellenado (paso 4) |
| 06–07 | salas / sala-detalle | Multiusuario: meta, ranking, chat, reacciones y logros |
| 08 | perfil-accesibilidad | Preferencias de voz y accesibilidad + "Lo que ReciApp aprendió de ti" |
| 09 | mis-solicitudes | Estados en tiempo real |
